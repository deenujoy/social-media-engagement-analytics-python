# Social Media Engagement Analytics Using Python

## 📌 Project Overview

This project analyzes social media engagement data using Python to uncover trends, user behavior, and content performance patterns. The analysis includes data cleaning, exploration, statistical analysis, feature engineering, and data visualization.

The dataset contains 5,000 social media records with information about users, posts, engagement metrics, sentiments, device usage, and audience reach.

---

## 🎯 Objectives

- Clean and preprocess social media data
- Handle missing values and duplicates
- Perform exploratory data analysis (EDA)
- Generate statistical summaries
- Create new engagement-related features
- Visualize patterns using Matplotlib, Seaborn, and Plotly
- Extract actionable business insights

## 📈 Key Findings

### Content Performance
- Engagement varies significantly across content types.
- Posts with higher impressions generally receive higher engagement.

### User Trends
- Verified accounts tend to achieve stronger engagement.
- Follower count positively influences engagement metrics.

### Geographic Insights
- Engagement rates differ across countries.
- Some regions show higher audience interaction than others.

### Sentiment Analysis
- Positive sentiment content generally performs better.
- Sentiment affects likes, comments, and shares.

### Behavioral Insights
- Device type influences watch time and engagement.
- Posting behavior impacts visibility and audience interaction.
